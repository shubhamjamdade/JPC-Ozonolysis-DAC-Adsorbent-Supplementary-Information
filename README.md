# Supplementary Information
Frequency_Estimations_For_Rate_Constants_Benzene.ipynb  and Python plots for Manuscript.ipynb notebooks were used for simulation data processing and visualization for results published in ** Jamdade, S., Cai, X., and Sholl, D.S. (2024). Assessment of Long-Term Degradation of
Adsorbents for Direct Air Capture by Ozonolysis. The Journal of Physical Chemistry C. **

The ZIP file contains DFT input files for all the geometry optimization and cNEB calculations described in this study. Additionally, MOF CIF files and python scripts utilizing thermochemistry packages have been included in the ZIP file. Electronic energies and Gibbs free energies data for all the cases can be found in XLSX file.
